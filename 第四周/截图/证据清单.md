# 第四周实操证据（云端 RTX 4090 跑通）

环境：MotrixLab **v0.3.0**，`uv run`，`--rllib=skrl --train-backend=torch --seed=42`

## 训练命令与模型路径

| 任务 | 训练命令 | best_agent |
|------|----------|------------|
| CartPole | `uv run scripts/train.py --env=cartpole --rllib=skrl --seed=42 --train-backend=torch` | `runs/cartpole/skrl/26-10-25_12-21-55-090874_PPO/checkpoints/best_agent.pt` |
| Pendulum A | 同上 `--env=pendulum`（默认能量奖励） | `runs/pendulum/skrl/26-10-25_12-22-44-980900_PPO/checkpoints/best_agent.pt` |
| Acrobot | 同上 `--env=acrobot` | `runs/acrobot/skrl/26-10-25_12-23-29-008041_PPO/checkpoints/best_agent.pt` |
| Pendulum B | 能量项 `0.0 * energy_reward` 后重训 | `runs/pendulum/skrl/26-10-25_12-27-43-111800_PPO/checkpoints/best_agent.pt` |

回放示例：

```bash
uv run scripts/play.py --env=pendulum --rllib=skrl --policy=runs/pendulum/skrl/26-10-25_12-22-44-980900_PPO/checkpoints/best_agent.pt --seed=0
```

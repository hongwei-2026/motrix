### 一、环境怎么搭

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone --branch MotrixArena-S1 \
  https://github.com/Motphys/MotrixLab.git
```

完整 LFS 很慢，先跳过指针文件。

越障地形 / 红包渲染 / 2026 掉落修复，在 starter_kit 的 `vbot_0218`：

```bash
# starter_kit → navigation2 → vbot_0218
# navigation_vbot.zip → motrix_envs/.../locomotion/vbot
uv sync --all-packages --extra skrl-torch
```

预训练权重也在 kit 里：
`runs/.../checkpoints/best_agent.pickle`

---

### 二、关键怎么跑

```bash
uv run scripts/play.py \
  --env=vbot_navigation_section01 \
  --num-envs=1 \
  --policy=runs/.../best_agent.pickle
```

无头机器记得开 Xvfb，再录屏留证。

---

### 三、踩过的坑

1. GitHub 网页看不到贴图？那是 Git LFS 指针，不是缺文件。
2. 仓库里找不着 vbot？资产在 starter_kit，不在 git。
3. `uv sync` 装 torch 超久？后台 nohup，别死盯 SSH。
4. 无显示器？Xvfb 顶上。

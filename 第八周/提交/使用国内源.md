# 本机 / VM 统一用国内源

结营及后续周作业，默认走国内镜像，避免 PyPI / GitHub 直连过慢。

## uv / Python

`MotrixLab/uv.toml`：

```toml
[[index]]
url = "https://pypi.tuna.tsinghua.edu.cn/simple"
default = true
```

环境变量（可选）：

```bash
export UV_DEFAULT_INDEX=https://pypi.tuna.tsinghua.edu.cn/simple
export UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
```

备用：`https://mirrors.aliyun.com/pypi/simple/`

## 其它常用

| 用途 | 国内源 |
| --- | --- |
| pip | `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| apt（若可配） | 阿里云 / 清华 Debian/Ubuntu mirror |
| GitHub 资源 | `https://ghproxy.net/` 或 gitclone / 镜像站（按可用性） |
| torch CUDA wheel | 仍可能需 PyTorch 官方 cu 索引；能镜像则优先镜像 |

规则：**能国内源就国内源；只有国内没有的包才回落到官方。**
